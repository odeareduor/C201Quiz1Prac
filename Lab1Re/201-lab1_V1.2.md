## 6 Redirection

When you execute the echo you compiled in Lab1 , it listens to the keyboard in the sense that any character you type on your keyboard is uppercased and printed by echo . If we have a particular text we want to feed this echo , we can redirect that text from a text file, and our echo would still think we are typing that text on our keyboard. Redirection from a text file into echo is done via the < operator. For example,

```
./ echo < readingBytes .txt
```

Analogously, we can redirect what our echo prints onto the terminal screen into a file. In that case too, our program would still think the text is being printed onto the screen. The relevant operator is > .

```
./ echo > output .txt
```

# 7 Archiving and zipping

An Archive is a repository for information that the user wishes to retain, but without requiring immediate access. The command tar can take multiple files and archive them in one file with a .tar extension which stands for tape archive. This command can also zip the resulting archive file so that it takes less space. In GNU/Linux machines, the zipped files have the extension .gz which stands for GNU Zip. Adding the ag -z to a tar command results into zipping. To archive and zip, use the

```
tar -czvf myTball .tar.gz file1 file2 file3 folder1 /
```

which outputs myTball.tar.gz a zipped archive of 3 files and 1 folder. Learn what each of those ags do.

Archiving more files/folders is analogous. For example, if you wish to tarball an entire folder named Lab1 , one method is to change the directory to the parent one using cd ../ , and then use the command

```
tar -czvf myTball .tar.gz Lab1 /
```

If you are interested, the command to extract a zipped archive file is

```
tar -xzvf myTball .tar.gz
```
